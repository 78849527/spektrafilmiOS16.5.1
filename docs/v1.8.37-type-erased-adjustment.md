## Runtime root-cause correction
Use explicit type erasure at boundaries that previously formed an
enormous nested opaque SwiftUI generic type:
1. featureRow and simpleSwitchRow now explicitly return AnyView.
   They still use horizontally scrollable lazy rows.
2. adjustmentControls now explicitly returns AnyView, consisting only
   of the two erased row views, divider and an erased detail container.
3. adjustmentDetailContent is a separate AnyView getter; it stays empty
   until the staged parameter load is ready.
4. Replace the former @ViewBuilder switch of nine deeply nested feature
   pages with activeSettings: AnyView, explicitly returning an erased
   branch for only the currently selected feature or EmptyView when
   disabled. This avoids demangling a giant nine-branch ConditionalContent.
5. Preserve staging, no whole-drawer transition animation and the same
   closable right-edge tap button. Left film/paper remains untouched.
6. No changes to source optics, RNG, Float64, export path, parameter
   defaults, the source-mode confirmation prompt or render scheduling.
