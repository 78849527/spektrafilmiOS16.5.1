# SpektraFilm iOS v1.8.17 — iPhone image precision boundary investigation

## Scope
This experimental release extends the **existing original Python 2D spatial DIR
parity diagnosis**, not its FIR/YVV mathematical model. The v1.8.16 A15 result
showed max error 5.55e-16 in the Double FIR/YVV source kernel, but max
0.0003137166 after the actual CIImage production path (1,287 channel pixels).

## What changed
- Add direct Float32 vs direct Float16 rounding truth vectors for the same
  upstream Python 13×11 fixtures.
- Measure the same 1287 input channel pixels through the current default-GPU
  CIImage RGBAf bridge and through a Core Image software renderer.
- Report the count of GPU values equal to IEEE Float16 rounded values and the
  count drifting beyond 1e-7 relative to direct Float32.
- Preserve the source 2D FIR/YVV and density/print algorithms and their error
  threshold (0.002). Do not automatically switch renderer based on these probes.
- iOS marketing version 1.8.17 / build 42; original release guard still
  requires true GPU, full RNG, Float64 whole-image and real iPhone evidence.

## Interpretation
CIContext's `render(... format: .RGBAf)` is an **output** specification;
it is not proof that its intermediate working buffers were 32-bit. iOS default
working format is RGBAh, and RGBAf working format is macOS-only according to
Core Image documentation. Neither the software nor GPU result should be
described as source-exact until verified. The purpose of this version is to
localize where quantization occurs before changing the actual pipeline.

## User device checks
1. Open app, import the same photo, check left wheels/right adjustments.
2. Enable **原版 DIR 空间显影** and **DIR 原版 FIR/YVV**.
3. Press **检测本机 Metal 显影内核** and copy the full diagnostics.
4. In the appendix **v1.8.17 原版图像精度边界诊断**, report both GPU and
   software bridge MAE/max and the Float16 signature count.
5. Test original-size export/save in Photos; record image dimensions,
   render errors, and any freezes. Original RAW and Numba stochastic thread
   parity remain unverified.

## Certification
This version is **EXPERIMENTAL / UNVERIFIED**. It does not establish exact
Numba RNG, full image Float64 RGB, RAW, JPEG parity or source material
certification. Numeric tests that pass on small fixtures are labeled as
fixture-scoped equivalence, not full-module certification.
