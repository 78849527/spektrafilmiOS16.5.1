# SpektraFilm iOS 16.5.1 — v1.8.47 Build72

## Scope: UI only

User request: merge original film/paper and adjustment into ONE editor, toggle
them by top text titles, make both film and paper horizontally swipable,
remove left/right edge-attached drawers, and open exclusively from a
bottom toolbar item visibly named **调整**.

The top title `调整` replaces the two material rails with the existing
first-row feature switches, second-row independent switches, and selected
advanced parameter details, unchanged from v1.8.46.

### Behavior

- One bottom entry only, `调整`. Tap to open the shared editor on the
  **调整** page; tap again or use X to close.
- Within the editor, tap top name `胶卷` to see film and paper; tap
  top `调整` to see the original adjustment controls. No bottom tab
  set, no side-attached tab, no dual overlapping drawer.
- Both materials are `ScrollView(.horizontal)` + `LazyHStack`,
  selected by tapping any card, auto-centering the active card when it
  changes. Swiping browses without inadvertently changing a selection.
- `selectedFilmID` and `selectedPaperID` bindings and parent
  `.onChange` still trigger the original spectral preview and
  persistent material ID. Double-tap row title resets to original
  film/print default stock.
- If positive/reversal film is chosen, paper rail is replaced by the
  existing no-print direct scan explanation.
- Keep material library button, the actual preview, photo import,
  compare, status/Metal report, save/export menus, original and
  precise algorithm UI plus all 10 third-level mini toggles.

### iOS 16.5.1 crash prevention

The adjustment settings tree uses existing segmented
`AnyView` boundaries; it is mounted in two separate main-thread
dispatch turns when opening or changing top tabs. The adjustment
values and nested switch semantics are not rewritten. No new parent
drag recognizer interferes with photo hold/compare or horizontal rails.

### Verification / unchanged scope

- `ios/scripts/validate_unified_bottom_editor.py` asserts a single
  bottom entry, top title navigation, two horizontal material rails,
  absence of all side-drawer components, important parent stock
  bindings, and staged mounting.
- `ios/scripts/validate_unified_switches.py` still checks all 10
  nested 28×16 pt switches, label double-tap restore and disabled
  original-source gates.
- iOS16.5 native Xcode compilation and unsigned experimental Release
  are separate gates.
- No changes to original Python scanner glare, Numba RNG, source
  spectral physics, physical DIR, Metal kernels, RAW, or colour pipeline.
  No new original image precision certification is claimed.
