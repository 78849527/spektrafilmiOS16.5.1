# v1.8.39 Build 64 — original TH-KG3-L source enlarger illuminant

## Exact upstream basis
- Python original `model/illuminants.py:standard_illuminant` includes
  `TH-KG3` and `TH-KG3-L`; latter is 3400 K blackbody × measured
  Schott KG3 heat filter × measured Canon 24mm f/2.8 IS lens
  transmission, normalized by the mean after filtering.
- The lens CSV is `data/filters/lens_transmission/canon/canon_24_f28_is.csv`,
  whose transmittance percentages are divided by 100 and interpolated
  at original 380–780 nm / 5 nm wavelength points using
  `scipy.interpolate.Akima1DInterpolator`.
- Original default TH-KG3 per-film/paper neutral CC database remains
  unchanged. The source neutral print filter lookup is ALSO keyed by
  illuminant; the nondefault TH-KG3-L lacks that database entry and
  therefore uses default (C,M,Y) = (0,65,55), NOT the TH-KG3 stock-specific
  CC values. This avoids an unoriginal mixed-illuminant hybrid.

## Native iOS changes
- Original Double illuminant is generated and embedded independently
  from the same measured source CSV; the fast mode also has an explicit
  Float32 representation but does not affect source Double selection.
- Opt-in native `OriginalPrintOptics.Settings.illuminant` chooses
  `thKG3` (default) or `thKG3L`; both full physical and preexisting
  original optical print routes receive the user setting by value.
- The film/paper print density stages and s023 source paper H-D
  interpretation remain unchanged.
- Enlarger first-row submenu has a source-lamp picker; v1.8.37
  type-erased root and the two-row adjustment controls remain unchanged.

## Numeric parity
- `validate_source_enlarger_lens.py` compiles actual unchanged Python
  source AST for `standard_illuminant`, `black_body_spectrum`, and
  `GenericFilter`, pinned to upstream blob identities. It compares
  the exact resulting TH-KG3-L Float64 81-point lamp to the embedded
  Swift array with max tolerance 1e-10, and confirms lens ≠ no lens.
- This is stage-level source numeric parity only, not an independent
  iPhone full-size RGB/Swift Float64 end-to-end certificate.
- No upstream diffusion-family 2D FFT, stochastic film grain / glare,
  RAW sensor calibration, or spectral CAM16 exactness is marked done.
- iOS 16.5.1 and the original strict certification/release gates
  remain as before. Experimental IPA remains unsigned until signing.
