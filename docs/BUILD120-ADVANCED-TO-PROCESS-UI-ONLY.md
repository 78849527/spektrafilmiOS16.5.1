# Build120｜高级设置归位工艺｜iOS 16.5.1 界面专批

## 目标
将“高级”从成像参数的第二入口，变为**只读验证概况／开发者诊断**。所有改变成像的参数在“调整”或“工艺”分阶段使用。

## 实际页面结构

- **胶卷**：胶片与相纸材料拨轮；反转片自动绕过相纸。
- **调整**：光线（曝光、混合强度）、色彩（光学 CMY 滤片）、质感（常用颗粒与光晕）、细节（常用扫描锐化）。
- **工艺**：顶部「快速冲印／精细冲印」与独立 8-bit DIR 像素处理。后面是「拍摄／胶片／相纸／扫描」四阶段。所有专业参数采用按需展开的 DisclosureGroup，未展开不占固定高度。
- **高级**：直接进入「验证状态与诊断」，或查看无成像开关的「验证概况」，可导出 LOG/JSON、执行 Build119 以前的诊断。保留完整诊断报告但不再调节光学参数。

### 工艺四阶段与原开关对照

| 阶段 | 常用入口 | 同页按需高级参数 |
|---|---|---|
| 拍摄 | Hanatos/Mallett 光谱、测光、摄影柔化 | Oklch/CAM16-UCS 四路线；Hanatos TC 重算、UV/IR 截止；高光恢复范围、保护 EV、镜头 μm；摄影 PSF 权重与滤镜 |
| 胶片 | DIR 层间扩散、背反射光晕、三亚层原版颗粒／快速颗粒 | FIR/YVV、扩散范围；乳剂散射倍率；SciPy/Numba；原版染料云、微结构参数 |
| 相纸 | 放大机、光学 CMY、曝光、预闪、印相柔化、s023 | 光源／中性滤镜数据库；预闪 M/Y；显影曲线乳剂层；印相原版 PSF |
| 扫描 | 原版光谱扫描、扫描眩光、扫描镜头、快速校准 | XYZ 眩光参数；原版镜头 σ 与 Unsharp；黑白场、曝光参考、旧 CAM16 LUT |
| 验证 | 高级菜单 | 诊断、阶段数值、Build119 大图证据；不影响照片 |

## 安全约束
- **不改原版 Python 光学数值链、Swift/Metal/Accelerate 实现、数据模型、依赖关系、默认值、颗粒种子、分辨率、导出、失败策略和 20% 内存安全门槛**。
- 保留现有 sourceModeControl 与 requestSourceMode 原版入口；所需依赖先确认、再切换，不静默开启不同算法。
- iOS16.5.1 拍摄与编辑面板仍保持单幅照片悬浮不动：固定底部面板、双层 DispatchQueue 按需挂载、AnyView 边界与独立阶段滚动。
- 原“高级”中部分私有 View/helper 源码仍保留编译，以维护老 Build100–119 审计；它们**已不再挂载成用户可见的高级参数页面**。控件实际绑定被当前“工艺”调用。需在完整真机交互和旧版本审计通过后才能删除历史兼容代码。
- Build119 实测：基础 13MP 合成 sRGB SciPy/Numba 真实 Float64 渲染已过；Python 整图对照、RAW/ICC、其他光学组合未认证。这次 UI 构建不改变上述认证边界。

## 验收
1. UI 源码审计确认「高级」无成像开关，四阶段的原参数绑定、折叠位置以及 8-bit/Float64 模式确认。
2. 全部前代 Python／Swift 数值回归；原版胶片三亚层和扫描器测试不变。
3. Xcode 真实 iPhoneOS arm64 编译和 IPA、版本/SHA/Release 同一性；未签名 IPA 非真机交互认证。
4. 下一次人工只需检查页面迁移、状态保持、滑块复位、底部浮动编辑区及单张照片预览是否稳定。**不重复 Build119 13MP 内存压力测试**。
