# v1.8.43 — Original Numba `fast_stats` single-worker Poisson/Binomial

Scope: diagnostics and exact-source numerical replay ONLY. No changes to the
production GPU grain path or an installed iPhone IPA.

## Scientific baseline

- Upstream reference `src/spektrafilm/model/grain.py`,
  Git blob `f2d2b23e3eab4f4a1d919f69bcb4aceb714e024d`.
- Actual upstream `src/spektrafilm/utils/fast_stats.py`,
  Git blob `9e80d29ce6b9f7820ae70f5c09da15edfaa70a0d`.
- NumPy 2.4.0, Numba 0.64.0, Python 3.13, `numba.set_num_threads(1)`.
- Explicitly seed `np.random` from inside `@njit`, **not** via Python
  process NumPy state. Warm JIT functions before seeding.
- `grain.py` calls the **entire Poisson array first**, then
  the **entire Binomial array**, not per-pixel Poisson→Binomial pairs.

## Implemented in Swift

- `OriginalSourceNumbaSingleThreadNormal.nextUniform()` consumes the
  source's legacy NumPy 53-bit uniform using two MT19937 words, without
  corrupting the normal cache.
- `OriginalSourceNumbaFastCounts.swift` reproduces the original branch
  thresholds, formulas, operation ordering and two-pass array consumption:
  - Poisson: nonpositive λ→0; 0<λ<30 Knuth; λ≥30 normal and
    nearest-even integer rounding, clamped at 0.
  - Binomial: p≤0→0, p≥1→n, n<25 Bernoulli direct,
    otherwise variance>10 normal/nearest-even/clamp; else the source
    inversion implementation, including the exact `k-1` return convention.
  - Numba fast mode's high-parameter normal approximation is **not**
    SciPy's exact PTRS/BTPE algorithm. Do not substitute one for another.
- Invalid values/array-shape and runaway safety conditions throw
  explicit errors; there is no distribution-equivalent silent fallback.
- `peekNextUniform()` works on a generator **copy** to verify RNG
  consumption without perturbing production-like array order.

## What is NOT certified

The upstream `@njit(parallel=True)` `prange` uses per-thread
independent Numba random states and scheduling, which are not reproduced
by a one-worker explicitly seeded diagnostic. The default
`use_fast_stats=False` SciPy path is a distinct algorithm. This module
is **not integrated in live Metal** and is not evidence for unseeded
source full-frame randomness, iPhone Float32 GPU parity, 16.5.1 UI
behavior, full-image RGB equivalence or signed release readiness.

Status: **数值等价（受控单线程 Numba 采样子模块）**; the complete
stochastic grain pipeline remains **近似实现 / 原版等价未认证**.
