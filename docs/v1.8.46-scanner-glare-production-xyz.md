### Genuine opt-in production pipeline

The **real** `OriginalSourcePhysicalImage.developInPlace` now has
a separate experimental NEGATIVE film paper-scanning path:

1. Full RGB image input → Hanatos camera photon optics → film initial H-D
   → source 2D DIR → corrected film CMY density (unchanged).
2. Source optical enlarger → optional full-frame paper-photon diffusion →
   absolute three-layer paper H-D (unchanged).
3. Source paper spectral density → normalized XYZ for every pixel:
   `SpectralPhysics.scanFilmDensity(...,sourceXYZOutput:true)` or
   `sourceSpatialScanPrintedPhoton(...,sourceXYZOutput:true)`.
4. `OriginalSourceScannerGlare.addToXYZ` runs on the **whole true
   paper XYZ image**, using the independently normalized source scanner
   illuminant XYZ from all 81 viewing spectrum × CMF samples.
   Source original order: 1-worker MT19937/Numba lognormal →
   2D reflect FIR/YVV → divide by 100 → add glare×illuminant XYZ.
5. Each actual modified XYZ pixel → original colour-science XYZ→linear
   sRGB matrix → original supported alternative ACES RGC gamut.
6. Optional source full-frame scanner-lens Gaussian and unsharp in
   **linear RGB**, followed by final display sRGB encoding.
7. Existing JPG preview/export original-size restrictions retained.
   The NO-glare code path stays byte-identical to v1.8.45.

### Controls

- Settings under third-level `DIR→8-bit 原版像素直连→逐像素全光学`:
  **源扫描 XYZ 眩光（单线程实验）**. Same shared 28×16 pt switch as
  all other menu levels.
- Default OFF; requires explicitly enabled full source physical mode,
  a negative/paper profile, source ACES, disabled Black/White and
  CAM16, and no old approximate CI scanner-finishing or grain.
- User source parameters: `percent=0.03`, `roughness=0.7`,
  `blur=0.5`, editable. The source Numba seed is **8888**,
  explicitly fixed for reproducible A/B and source vector comparison.
- Zero-percent or disabled mode does not consume RNG and keeps legacy
  output. If a nonzero glare is requested without a seed or on a
  reversal film, an explicit error is returned. No hash-noise or
  fallback to CI/SciPy.
- Conservative extra source memory allowance: **96 bytes/pixel**,
  included in both actual original frame processing and pre-export
  budget confirmation. The iPhone may decline high-resolution images
  instead of resizing or silently changing precision.
