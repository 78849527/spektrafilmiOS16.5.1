## New source code port, not a repeat of independent 1x1 RGB probes

In source `src/spektrafilm/model/couplers.py`, spatial DIR computes inhibitor silver/CMY -> stock-specific donor-to-receiver matrix -> `fast_gaussian_filter` plus `fast_exponential_filter` -> log10 exposure subtraction -> pre-DIR H-D density. Source `src/spektrafilm/utils/fast_gaussian_filter.py` dispatches:
- `sigma < 3.0` **separable FIR**, truncate radius `int(3*sigma+0.5)`, original half-sample *reflect* boundaries.
- `sigma >= 3.0` Young–van Vliet recursive third-order **IIR**, source coefficients, sample-replication initial and backward boundary state, horizontal then vertical.
- Source exponential tail is a three-Gaussian mixture, exact hardcoded amplitudes `0.1633/0.6496/0.1870` and sigma ratios `0.5360/1.5236/2.7684`. These approximate the physical exponential PSF **as they do in original upstream**, not as an iOS-only replacement.

Previously spatial DIR was a **CoreImage Gaussian approximation** with different boundaries and radius clamping; v1.8.16 adds `SourceSpatialDIRConvolution.swift` implementing original FIR/YVV with Double arithmetic. `SpatialDIR.apply` uses the source branch by default whenever user enables spatial DIR. Its explicit mobile CI Gaussian path remains selectable from the editor under **DIR 原版 FIR/YVV** (off = prior fast approximation). Failure of source convolution is an error, NOT an automatic fast-mode downgrade.

Production: `Hanatos 2025→camera exposure→initial film measured density→donor/receiver inhibition→original source FIR/YVV diffusion→pre-DIR corrected H-D→grain density→optical print/scanner RGB`. Actual Core Image bridge renders intermediate inhibitor RGB as IEEE754 Float32 into Double convolution, then packs Float32 back to CIImage. **This is not a pure Float64 whole-image pipeline**. Existing grain is unchanged, and entire source Numba random grain remains unverified.

## True 2D reference, including original Core Image processing path

`ios/scripts/generate_source_spatial_dir_2d.py` imports and executes **the real upstream** `fast_gaussian_filter.py` and `model/couplers.py`. It generates three nonuniform, multichannel 13×11 images using original measured stock matrices, two negatives and one positive, several spatial scales, exponential-tail weights, reflect boundaries and source sign reversals. Reference contains 3×13×11×3 = **1,287 sample channels** for original inhibitor, full 2D diffused inhibitor, corrected exposure and normalized final output.

`SourceSpatialDIR2DParity.evaluate()` compares original Numba NumPy Float64 diffusion against native source FIR/YVV and against **the actual production `SpatialDIR.apply`** via identity LUTs. It reports MAE, max and exact worst pixel/channel, counts channels where absolute error is above 0.002. App adds an independently pass/fail/error report appendix without modifying original 8/8 hardware count. Mac CI independently runs the same native 2D checks and prohibits passing at >0.002.

## Important safety/scoping boundary

Exact spatial source convolution on full-resolution photos is CPU/memory intensive. Preview and export both use the same stage; unsupported image extents and invalid values **throw and display errors**, no silent fast fallback. Mobile fast Gaussian is available explicitly from UI to maintain usable throughput.

The source arrays are a small fixed 2D image test, NOT independently Python-produced final full-camera-RGB photos, not spatial random grain, and not source-matching Numba RNG. The other v1.8.15 stages and high-resolution Photos save/export are unchanged. Full-device Apple A15 diagnostic appendix plus real-photo preview/export validation will still be required after GitHub CI.
