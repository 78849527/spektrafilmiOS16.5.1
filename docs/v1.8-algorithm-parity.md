## 状态词典

- **完整移植**：源算法、参数、运算顺序、边界条件和依赖均已落地；仍不自动代表数值对照通过。
- **数值等价**：指定原版 Python 参考、真机 Metal 输出、统计分布和最终图像误差均通过。
- **近似实现**：数学模型部分吻合，但 PRNG、Float32、滤波路径、边界或相关性仍不一致。
- **尚未移植**：没有实现或还未接入生产路径。

## v1.8 硬性验收门槛

1. **算法**：先确认上游源码 SHA、默认参数与有无 `use_fast_stats`；算法的每条分支、循环、阈值和顺序都需要对齐。
2. **随机数**：对照分布的均值、方差和分位数只是统计门槛，不能替代原版的逐像素随机流验收。
3. **滤波**：sigma<3 源路径是 reflect FIR；sigma≥3 是 Young–van Vliet 3 阶递归、水平然后垂直、边缘延拓。有限 halo 的 tile FIR 不能替代 IIR。
4. **实际 GPU**：托管 Intel macOS runner 曾出现 GPU 指令完成、输出却全零；因此独立执行 texture probe 与真机 GPU 输出。
5. **完整图像**：固定胶片、相纸、分辨率、参数及种子，对比中间 32-bit 光学密度与最终导出（最低要求：MAE/RMSE/max abs，色彩 deltaE，灰度/颜色分布、分块接缝）。
6. **回归**：iOS16.5.1、双拨轮、悬浮预览、双击复原、直存相册、完整分辨率 98% JPEG。
7. **版本**：所有证据需要与 Git commit SHA 关联，CI 和 Release tag / IPA asset 需要相同 SHA。未达到全部条件只提供 **UNVERIFIED TEST** IPA，不可称“精确移植已完成”。

## 本轮已提交的真实源码

- `OriginalMetalGrain.swift`：IIR 未接入时遇到 sigma≥3 抛出明确错误，禁止 FIR 静默降级。
- `OriginalGrainKernels.metal`：增加 YVV 递归的四个行/列 Metal kernel。
- `OriginalMetalIIR.swift`：源 Float64 系数计算 → Float32 Metal 参数 → 全图四遍顺序执行（独立、尚不用于生产）。
- `generate_source_iir.py`：从原版 `fast_gaussian_filter` 调用生成冲激/渐变、三色不同 sigma 的原版参考图。
- `OriginalMetalIIRValidation.swift`：实际 GPU 全像素与上游基准比较，最大绝对误差临时测试阈值 5e-4；该阈值不是整个产品精确性的证明。
- GitHub Actions：新增 Numba 运行原版参考及 YVV GPU 测试；只有通过硬件对照才可能正式发布。

当前没有足够证据把上面的任何“近似”或“尚未”改成“数值等价”。
