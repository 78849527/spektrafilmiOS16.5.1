### Native port

`OriginalSourceScannerGlare.computeAmount` implements the actual
`compute_random_glare_amount` source ordering:

1. lognormal parameters from original linear-space `mean=percent` and
   `std=roughness*percent`, preserving the low-`sigma` no-RNG branch.
2. Source MT19937/Numba cached Marsaglia Gaussian draws with **one
   explicitly seeded worker**, or an explicitly supplied full source
   Gaussian array; never synthetic per-pixel hash noise.
3. The same original full-frame `fast_gaussian_filter`: 2D
   reflect-edge FIR for sigma below 3, Young–van Vliet IIR for sigma at
   least 3. Reuses the existing production `SourceSpatialDIRConvolution`
   Double kernel with identical copies in the 3 color lanes; it does
   **not** generate independent random samples in each color.
4. Divide filtered field by **100**, after blurring.
5. `addToXYZ`: `xyz[p,c] += field[p] * illuminantXYZ[c]`.
   Requires the scanner's actual XYZ domain, not displayed sRGB.

The native API explicitly rejects invalid input, missing/randomness
mode, and nonfinite output. Source `active=false` and `percent<=0`
leave XYZ unchanged.

### Critical boundary

The original default `@njit(parallel=True) prange` Numba RNG is
**unseeded with multiple worker states**. One seeded worker, even with
exact output vectors, does **not** certify the default scanner field.

The scanner's print/film XYZ->RGB production pipeline has not yet
been re-ordered to insert this random field *after black/white XYZ
correction and before XYZ->RGB/gamut*. The existing mobile scanner
glare is still an explicitly approximate effect. This port is a
**validated diagnostic submodule**, not a replacement for the complete
production pipeline, and its presence in an IPA must not be described
as a completed source scanner visual feature.

No algorithms, source RNG defaults, mobile scanner looks, iOS16.5 UI,
JPEG export or reference precision baselines are automatically
modified. Do not claim full RGB Float64, RAW or physical-device
certification from the local stage test.
