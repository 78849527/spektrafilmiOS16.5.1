# SpektraFilm v1.8.35 Build 60 — two-row direct feature navigation

## User-requested layout (clarified)

The adjustment panel is no longer a compact-switch row followed by a
redundant category row (基础 / 扫描 / 印相 / 光学 / DIR / 颗粒).
It has exactly TWO top rows, and a lower parameter region.

1. **First horizontal row — features WITH submenus or controls:**
   基础, 扫描, 锐化, 放大机, 预闪, s023, 光晕, DIR, 颗粒.
   - 基础 has no on/off state. Tap its label to expose original film/paper
     exposure controls and LUT strength directly.
   - For every on/off feature, tapping the title turns it ON if necessary
     and opens its OWN submenu immediately; tapping an already-enabled
     title selects its controls without disabling it.
   - The mini 28x16 toggle on the same chip explicitly toggles the
     function. Turning it OFF immediately removes its submenu.
   - No feature panel is visible when its own switch is OFF; downstream
     options retain all upstream guard conditions.
   - 预闪 is now direct, NOT buried under 印相. The enlarger must first
     be enabled for preflash to become actionable; source optical
     semantics and ordering remain unchanged.

2. **Second horizontal row — switches with NO own submenus:**
   64位 Hanatos, 乳剂散射, plus context-dependent CAM16, 按印相曝光参考,
   印相归一化, 拍摄曝光补偿, SciPy source RNG, 离散 Poisson.
   They are displayed only when their respective parent setting path
   is active. A switch is an on/off operation; double tapping restores
   the original Boolean default, including TRUE for print exposure
   normalization / shot-exposure compensation. No third category
   selection row exists.

3. **Lower content region:** only the parameters of the feature last
   selected in row one, and only while enabled. In particular the
   printed CMY values, original preflash exposure/M/Y, s023 H-D paper
   curves, scanner calibration, halation strength, original spatial DIR,
   8-bit physical source pathway, and grain/Metal diagnostics remain.
   Child options that have descendants remain in their parent submenu.

This is an iOS 16.5.1 SwiftUI UI-only change based on the original
v1.8.34 Build59, with the v1.8.32 source scattering/halation fix
intact. No Python reference baselines, film chemistry/optics, float
precision settings, iOS minimum, or export safety guards are changed.
Full device parity and Numba RNG are not implied by successful build.
