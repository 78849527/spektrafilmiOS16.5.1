# SpektraFilm iOS v1.8.12 — original 256-node s023 print H-D and contiguous negative-print RGB

Parent: v1.8.11 / Build 36, Apple A15 8/8 user-verified. Parent source direct reversal scan and developed-paper scan each achieved 0/72 exceeding 0.002; six direct optical print vectors also passed. v1.8.12 Build 37 retains iOS minimum 16.5.

## Actual source discrepancy

Original Python `PrintingStage.develop` invokes `develop_print_morph`, whose `apply_print_curves_morph` evaluates **the 3-layer CDF fitted density model at all 256 source log exposure values**, including identity settings; `fast_interp` then interpolates that absolute fitted H-D characteristic. The prior native code used raw measured profile density curves in the identity case, and `measured + fitted-morph delta` when adjusted. That is mathematically different from the original fitted CDF model. It was not enough to test the 3-layer model in isolation; the production optical printing path must USE that actual model.

v1.8.12 adds `OriginalPrintMorph.SourceCurve` (source 256-node CDF, exact zero-input/saturation endpoints and right-biased fast_interp interpolation) and `prepareSource`, allocating CDF samples once per stock/effect setting. The **original print optics enabled** production path now uses absolute source paper H-D without measured-curve mixing or synthetic Dmax clamp. The previous non-original/legacy measured-density path stays unchanged; missing source CDF model fails explicitly rather than silently degrading. Earlier v1.8.11 independent dye/base/sensitivity NaN masks stay enforced in optical print and preflash.

## Independent source and native numerical checks

1. `PrintMorphValidation.swift` repeats 840 genuine original-Python s023 sample checks through the new **absolute native 256-point source H-D interpolator**, in addition to prior fitted CDF tests (8 print stocks x 7 morph configurations x 5 exposure taps x 3 channels).
2. `generate_source_negative_print_chain.py` creates 18 full-contiguous-stage vectors from original source optical formulas, actual profile CDFs and Python source paper scanning. The vectors cover 6 negative-film × paper/film combinations and morphology modes (neutral/gamma, RGB, layer-specific, exhaustion, mixed) at three already-developed negative CMY densities each.
3. `OriginalNegativePrintChainParity.swift` runs the **same production implementation** to check optical raw, paper log exposure, fitted paper CMY density, CIE XYZ, linear sRGB, ACES RGC, and final display-clipped sRGB, with per-stage MAE/RMSE/max and fail-closed 0.002 threshold. The diagnostics additionally require that the production `scanFilmDensity` output equals traced output.
4. Keep v1.8.10 reversal and v1.8.11 developed-print-stage RGB (72+72 channel) references and native hardware 8/8 UI diagnostics unchanged.

## Crucial scope

The continuous chain starts at **already-developed negative CMY densities** and bypasses RAW input, Hanatos camera spectral capture, film H-D/DIR, source Numba-thread random stream, full-resolution spatial diffusion/grain, image-space color conversions, scanner glare/B&W calibration and default CAM16 gamut (the source's optional ACES branch is selected). Optical neutralization is disabled for these vectors to isolate source pipeline functions deterministically; print exposure, preflash, CMY filtration and six independent H-D morphs are exercised. Display encoded sRGB clipping to [0,1] is explicit and matches native display output. The 0.002 threshold does NOT establish Float64/Numba RNG/full-image bit-exactness.
