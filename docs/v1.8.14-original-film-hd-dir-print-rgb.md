## This version extends the input one native stage upstream

For 6 combinations of original negative film and print medium, 3 log-exposure vectors each = **18 independent test cases ×3 channels =54**, the generator carries original Python source output through the unchanged source Schott KG3/dichroic enlarger, NaN-to-zero-light spectral transmission, preflash, original s023 256-point fitted three-layer absolute paper H-D, CIE 1931 XYZ, ACES RGC and sRGB CCTF.

## Scope and certification

Input is **known film log10 exposure**, after camera spectral capture; this does **not** validate camera RAW or Hanatos capture response/correction surface, autoexposure, spatial DIR diffusion, stochastic grain, Numba random thread streams, full image pixels or Float64 whole-image exactness. Source Float64 vs packed iOS Float32 spectra may have small measured error and is gated to 0.002. Source optical print testing deliberately sets paper exposure normalization/BW calibration off and ACES on so source stage comparison is isolated; do not interpret as default pipeline full-image parity. The Apple A15 test is only certified after user sends the new appendix report. GitHub macOS CPU numerical CI does not stand in for Apple A15 hardware.

CI must run source generator, produce the source reference Swift file, compile all original/native stages, and show 54-channel stage output with zero values over threshold; full iPhoneOS Release compile and the experimental signed-install-needed IPA publish follow.
