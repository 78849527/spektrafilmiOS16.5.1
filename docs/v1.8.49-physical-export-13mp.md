# SpektraFilm iOS 16.5.1 v1.8.49 Build74 — 13MP source physical output + explicit safe export

## Inherited optical math; no source algorithm changes
- Upstream `src/spektrafilm` is unchanged and remains the only numerical reference.
- The original per-pixel physical pipeline keeps Hanatos/Mallett camera photons, film H-D, source 2D DIR, measured three-layer density grain (SciPy Poisson→Binomial, dye clouds, controlled Numba single-worker microstructure, FIR/YVV), optical enlarger, paper and scanner in their previous order.
- An output resize is **only** applied by explicit user selection, via an ImageIO sRGB 8-bit thumbnail and high-quality Quartz sampling **before** any original physical calculation. The calculation runs at the new pixel size; no decoded RGB post-render up/downsample and no fallback to the mobile fast 3D LUT.
- Original-resolution mode never resizes and remains limited to 13,000,000 pixels, maximum side 8192.

## Export options
1. 原始分辨率: metadata preflight now admits 4032×3024 (12,192,768 px), conditional on the unchanged real physical/process memory budget.

3. 省内存分辨率: user-confirmed target under 3MP and 30% of current effective memory budget. Up to 16MP source files.
- No silent resampling, silently skipped grain, color profile conversion, RAW downgrade, bit-depth substitution, or algorithm switch.
- Plain 8-bit original DIR-only route still exports its original dimensions; user-selected safe/economy applies to the independent full-physical source route.
- JPEG remains quality 98% after complete original-ordered physical processing.

- True image dimensions 4032×3024 accepted at metadata gate; explicit 4000×3300 rejected.
- Memory guard MUST reject source 4032×3024 with the 272 extra bytes/pixel of full source grain on a simulated 4GB iPhone. This is expected, not a bug.
- A 1600×1200 source-grain physical output passes deterministic simulated 4GB RAM, 1.2GB process headroom guard.
- ImageIO sRGB 8-bit resize is tested for exact selected geometry and deterministic repeat. Display P3 input is rejected on both normal and reduced routes.
- Existing independent Python v1.8.48 source grain comparison and full frame parity tests remain mandatory. Compiler/device bundle testing and strict final certification reject remain active.

**Limitations**: iPhoneOS CI compile alone is not real-device runtime or native full-size Python↔iPhone RGB/RAW numerical equivalence. Original unseeded Numba prange parallel stream remains unported. This is an experimental unsigned test build until signing and on-device evaluation.
