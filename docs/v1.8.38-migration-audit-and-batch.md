## Status vocabulary
- **完整移植**: source formulas, parameters, defaults, order, domain,
  boundaries and dependencies present on the real iOS production path.
- **数值等价**: independent original Python vs native Swift/Metal stage
  evidence passes; scope, precision and test input must be stated.
- **近似实现**: mobile/Core Image/Float16, visibly plausible but not source.
- **尚未移植**: absent from iOS production or only a diagnostic prototype.
A module may have the implementation present while certification is pending.
No CI step may silently upgrade it to full-device source equivalence.

## Implemented in this batch (v1.8.38)
1. **Original camera rgb_to_raw_mallett2019** — upstream
   `runtime/stages/filming.py:_rgb_to_film_raw`,
   `utils/spectral_upsampling.py:rgb_to_raw_mallett2019`.
   Existing Float64 measured 81×3 film spectral sensitivity + original
   Mallett 2019 basis now calculate the true un-clamped source raw
   (before exposure EV, original H-D and DIR) as a selectable alternate
   to the default Hanatos 2025 physical-image method. Its matrix uses the
   actual film reference illuminant: D55 for daylight / T for tungsten.
   `sourceCameraRaw` and `sourceSpatialInput` both dispatch to the
   selected algorithm, so source camera on/off takes the same route.
2. **Original camera filter_uv/filter_ir** — upstream
   `model/color_filters.py:compute_band_pass_filter`,
   `runtime/params_schema.py:CameraParams`. The full original source
   81-wavelength erf UV+IR passband and per-emulsion illuminant-weighted
   sensitivity normalization feed Mallett's original spectral einsum.
   Both have independent strength/center/width and default OFF.
3. **Source guards**: Hanatos TC response is generated for unfiltered
   sensitivity. With an active UV/IR filter, the port requires selected
   Mallett 2019 rather than silently ignoring it or pretending to have
   rebuilt the Hanatos LUT. This limitation is explicit, and NOT a claim
   that the original Python Hanatos lacks UV/IR support.
4. **Verification**: independent original Python all 20 film matrices
   (D55/T, with/without UV/IR) against source `rgb_to_raw_mallett2019`;
   native Swift production erf transmission for 4×81 samples against
   SciPy erf with 5e-15 stage tolerance. Both are stage-scoped; iPhone
   end-to-end numerical certification still must be performed.
5. Old Hanatos, fast LUT, material arrays, original film/paper/DIR,
   memory budget, signed release restrictions, iOS 16.5 minimum,
   two-row editor and type-erasure crash mitigation remain unchanged.
