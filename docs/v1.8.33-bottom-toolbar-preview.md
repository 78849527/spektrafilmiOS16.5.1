# SpektraFilm iOS v1.8.33 Build 58 — bottom menu + upward photo preview

UI-only change based on v1.8.32 Build 57, iOS 16.5.1.

## Requested placement
The original camera/import/LUT/save/share/compare/visibility toolbar moves
from the top overlay to the bottom of the safe-area window, without
changing buttons, callbacks or the main rendering pipeline.
The existing top diagnostic/status strip stays above the image whenever
floating controls are displayed. The image starts immediately below
that strip with a 4pt layout gap and aligns to the top of the remaining
photo area instead of vertical-centering unused black space.
For zoomed images the scale anchor is top; hold-to-view original,
double-tap zoom and before-after split remain intact.
The separate film/paper and adjustment floating docks shift to sit
63pt above the bottom edge so they do not cover the toolbar.
Their expand/collapse, drags and original positions otherwise remain
unchanged. App navigation bar is still hidden.

## Regression
CI preflight asserts report->image->toolbar hierarchy, removal of top
toolbar overlay, top image zoom anchor, retained Metal report sheet and
original long-hold comparison. iPhoneOS Release build is required to
prove SwiftUI compiles; real-device visual placement remains unverified
until installed and tested.

This patch does not modify any Python baseline, Swift/Metal algorithm,
float precision, presets, photographic parameters, memory guard,
camera capture, source 12MP full-frame export cap or certification gate.
