The user confirmed A15 v1.8.18 hardware test **8/8**, including native

## Real production experiment (new)
Opt-in right-hand adjustment setting: **8-bit 原版像素直连（实验）**,
inside **原版 DIR 空间显影 → DIR 原版 FIR/YVV**.

For compatible inputs the actual preview and JPEG export route is:
`source JPEG/HEIC/PNG Data → ImageIO CGImage → Quartz 8-bit sRGB RGBA
(no CIContext) → Double source RGB → production LUT+source inhibition+
Double FIR/YVV → Double print RGB → 8-bit sRGB CGImage → ImageIO JPEG`.
The final CIImage from `applyExactImagePath` is explicitly suppressed;
the original Double print-array observer supplies the result.

ImageIO's 8-bit decoding is the naturally quantized encoded input, NOT
Float64 raw sensor data. JPEG output necessarily has 8-bit quantization and
lossy encoding. The input-output chain is **NOT** full source algorithm
certification and not whole-image Float64 output.

## Strict supported scope
- Only source `bitsPerComponent==8` opaque images with explicitly identified
  sRGB RGB colour space. Display P3, grayscale, untagged, and other colour
  profiles fail closed; Quartz MUST NOT silently convert to sRGB in precise
  mode. Rotate via EXIF 1..8.
- Source FIR/YVV enabled and original measured DIR+film+paper data available.
- 100% effect strength.
- NO density grain, extra scatter/halation or scanner-finishing effects.
- Original-resolution export ONLY in direct mode; safe-resolution choices
  produce a clear error (user may explicitly turn off this mode).
- Up to 16MP / side ≤8192. Do not silently shrink. Larger files fail with
  explicit error instead of crashing or silently choosing CI half precision.
- Other modes are unchanged; previous CI renderer is still the default.
- No silent fallback if the explicit direct route errors.
