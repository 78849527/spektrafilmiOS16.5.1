# SpektraFilm iOS v1.8.31 Build 56 — source scatter and halation

Original Python model.diffusion.apply_halation_um is ported into the opt-in
full-image Double photon pipeline after lens blur and before film H-D.
Source order: scatter then back-reflection halation. Original params from
runtime.params_schema.HalationParams; default independent source toggle OFF
preserves v1.8.30.

Scatter: E1=(1-s)*E0+s*((1-w)*G(core)*E0+w*Exp(tail)*E0).
Core Gaussian uses source 2D reflect FIR below sigma 3 and Young–van Vliet
IIR otherwise. Exponential is the original three Gaussian surrogate with
weights 0.1633/0.6496/0.1870 and sigma ratios 0.536/1.5236/2.7684.
All three channels have original individual sigma/core/tail/weight values.

Halation: E2=E1+a_total*sum_k(rho^(k-1)/sum_j rho^(j-1)*
G(sigma_h*sqrt(k))*E1), N=3 rho=0.5; source defaults strengths
(0.05,0.015,0), sigma (65,65,65) micrometers and normalization
E2/(1+a_total). The original full 3-channel photon frame is never
tiled or subsampled. Additional Double memory is preflighted separately.

Independent Python function references generated for combined operation,
different spatial scales, scatter-only, halation-only and zero-effect
identity. Original four upstream source blob identities remain pinned.
Swift native numeric tests compare all pixels in each reference field.

Limitations: Other source camera diffusion filter, UV/IR sensitivity
filtration, true RAW decoding, stochastic Numba RNG and source scanner
random glare are not certified. This is not an end-to-end full-image
Python-vs-real-iPhone numerical certificate.

User acceptance: source full-optics mode, old display scatter/halation OFF.

Switch ON and test gains 0/0, 1/0, 0/1, 1/1 and scale changes against
