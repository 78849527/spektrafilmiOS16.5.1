# v1.8.29 Build54 — NextLevel professional still capture and DNG

This stage **finishes a practical pro-photo capture surface**, not the
entire NextLevel framework. All original SpektraFilm Python physical
processing remains on its pre-existing, separate opt-in routes.

## Code delivered

- Maintains iOS 16.5 minimum and local MIT NextLevel 0.18.0 package.
- Capture formats: high-resolution JPEG, HEIC and native Bayer DNG + JPEG
  dual capture. DNG is only offered on a selected device exposing an actual
  availableRawPhotoPixelFormatType; raw capability checks are repeated at
  shutter time. If DNG is missing, handoff FAILS rather than downgrading.
- Chooses front, main wide, ultra-wide and tele camera only where the
  physical device actually supports the built-in camera hardware.
- Real NextLevel preview, tap focus/exposure, 3-state flash, zoom slider.
- Manual ISO, shutter, focus lens position, white balance temperature/tint,
  exposure compensation (auto mode). Every requested value is validated
  against the active AVCaptureDevice; failure is reported explicitly.
- Original DNG file is written atomically to Files / On My iPhone /
  SpektraFilm Port / SpektraFilm RAW. The DNG can also be shared via
  the new document icon in the floating editor.
- The matching camera-processed JPEG (in RAW mode) or HEIC/JPEG input
  is passed unchanged to the existing PhotoEditorModel.loadPhoto, then
  the currently selected film/paper simulation and full-resolution export.
- No microphone permission or audio/video recording activated in this
  still-camera capture mode. No silent render-algorithm fallback.
- NextLevel upstream isRawCaptureEnabled was an unimplemented TODO in
  0.18.0; only its RAW capture configuration and the separate additive
  manual controls extension are patched.

## Strict limitations

- **Bayer DNG does NOT imply Apple ProRAW**. The iPhone must expose raw
  format support; user device may not.
- SpektraFilm's Python original RAW sensor pipeline is **not** yet
  ported. The dual-capture companion JPEG is what enters film printing;
  the original DNG is preserved unmodified for future true RAW development.
- This is photo capture only. NextLevel video capture, Live Photo,
  portrait mattes/depth and ARKit are not part of this stage.
- SwiftUI camera UI and hardware RAW pairing need real-device validation.
  This version is an unsigned experimental IPA until signed and tested.
- Numerical equivalence of complete upstream stochastic grain/Float64
  full-image paths is still not certified. Keep the existing fail-closed
  source-precision gate.

## On-device functional test checklist

1. Camera launches and live preview appears on a physical iOS16.5.1 iPhone.
2. JPEG capture returns to original floating editor, with same film/paper.
3. HEIC capture also imports, previews and exports at original resolution.
4. Test front, wide, ultra, tele only if physically available, including
   orientation after capture and switching the lens more than once.
5. Test tap to focus; Auto EV, manual ISO/shutter, manual focus, WB,
   zoom and flash where actual hardware supports each feature.
6. On an iPhone reporting RAW available, select DNG+JPEG and shoot.
   Confirm DNG share icon, intact DNG bytes and JPEG print preview.
   If RAW not supported, selection must be disabled and/or fail
   explicitly, NOT quietly capture a JPEG.
7. Test previously selected raw file remains separate from changing
   film/paper, and verify camera cancel leaves prior source untouched.
8. Re-run Metal 8/8 and 10 MP full physical output validation separately.
