# SpektraFilm v1.8.27 Build 52 — original H-D interpolation numerical gate

Base: v1.8.26 commit `4ee96de1b29683e44445054ec1ef9742d114e28b` (includes v1.8.25 `2944aaba`).

## What changed

- Add an independent source Python reference generator for all **20 camera film profiles** (including **four reversal** stocks).
- Generate original Float64 H-D expected density with actual upstream
  `spektrafilm.model.density_curves.interpolate_exposure_to_density` /
  `spektrafilm.utils.fast_interp.fast_interp`. Pre-DIR corrected curves
  are computed using actual upstream `compute_density_curves_before_dir_couplers`.
- Probe real original 256-point exposure grids, endpoints, outside-range
  clamping, exact nodes, midpoint intervals and deterministic non-node
  positions. No fabricated interpolation references or mobile LUTs.
- Expose the production `SpectralPhysics.Profile.curve` through a
  read-only numerical diagnostic, and compare its **source Float64** outputs
  against Python in native Swift. Fail if any channel differs by more than
  `2e-11` absolute; print maximum and mean error.
- Run the independent reference generator and native test inside the
  existing GitHub Actions physics suite. Keep original full-image
  regression, Metal tests and fail-closed certification checks unchanged.
- New branch/build/release namespace prevents overwriting earlier
  experimental v1.8.25 assets. Fast mobile H-D path is unchanged.

## Limited certification scope

Passing this new test would support **numerical parity for measured film
H-D interpolation at the tested scalar inputs only**. It does not certify
the complete original film/print/RAW pipeline, whole-device color
precision, source Numba RNG, stochastic grain, GPU dispatch, or the
full-resolution iPhone image. The prior original Python seven-stage
nonlinear image fixture remains an independent pipeline test, not a
substitute for physical hardware validation.

Never rename an experimental unverified IPA as fully certified based on
this test. If any gate fails, label the build failed and do not supply
a new IPA link as fully validated.
